# Web Slot Simulator

Flask（Python）をバックエンド、JavaScript/HTML/CSSをフロントエンドに用いて制作した、ブラウザ上で動作するパチスロシミュレーターです。

実機のような出目判定、フラグ抽選、リール制御をWeb技術で再現しています。

---

## 主な機能

- **スロットゲームエンジン（バックエンド）**
  - レバーオン時の役抽選（リプレイ、ベル、スイカ、チェリー、ボーナス等）および内部状態管理
  - リール配列および停止ボタン押下位置に基づいたスベリ・停止制御（引き込み・蹴り）
  - 成立役に応じた払出枚数・クレジット計算
- **リール描画・演出（フロントエンド）**
  - CSS / JavaScriptを用いたリール回転・滑らかな停止アニメーション制御
  - ボタン操作（BET、レバー、ストップボタン）に応じたUI更新
- **非同期通信（API連携）**
  - フロントエンドとFlaskサーバー間でJSON形式を用いた非同期通信処理
- **デバッグ・検証用モジュール**
  - 特定役の成立確認や境界値テストをコマンドラインから即座に検証できるスクリプトを内包
