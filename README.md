# Hobby Projects

個人開発および検証用のプロジェクトを管理しているリポジトリです。

## 主なプロジェクト

### 1. Web Slot Simulator (`/slot`)
Flask（Python）とJavaScript（Vanilla JS / CSS）で制作した、ブラウザ上で動作するスロットシミュレーターです。

- **バックエンド**: 役抽選ロジック、リール停止制御、ステート管理 (Python / Flask)
- **フロントエンド**: リール回転・停止アニメーション、非同期API通信 (JavaScript, CSS, HTML)
- **詳細・動かし方**: [`/slot` ディレクトリのREADME](./slot/README.md) を参照してください。
